# UPI Studio

A responsive single-page UPI QR generator with editable UPI ID, payee name, amount, and payment note.

## Run
Open `index.html` in a modern browser. No build step is required.

## Publish
GitHub Pages is configured to serve the root of the `main` branch.

## Privacy and payments
The app does not store user data or process payments. QR image rendering uses the public QRServer image endpoint. Verify the UPI ID and amount before sharing any QR. A QR code is only a payment request, not proof of payment.
